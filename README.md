# Plataforma de datos para recetas y wearables

Proyecto del curso **INF3862 — Plataformas Big Data para Data Science**
(Magíster en Inteligencia Artificial, PUC). Profesor: Sebastián Hagedorn.

## Caso de uso

Una aplicación de recetas construida sobre Food.com integra relojes inteligentes: sabe qué recetas
prepara cada usuario y cuánta energía gasta cada día. El proyecto construye un **panel de balance
calórico diario**: calorías consumidas (recetas preparadas × porciones × calorías por porción del
catálogo) frente a calorías gastadas (reloj), por usuario y día, con tendencia a 7 y 30 días e
indicadores agregados para el equipo de producto.

 Combina los datos del wearable con las recetas de Food.com
(las reseñas son fuente secundaria).
